初版：2026-09-11；更新：2026-09-14。用户已确认；操作文案使用“中止”，不改为“停止”。以下“统一刷新”与“近期已实施能力”优先于后文初版及历史验收说明。

## 统一刷新（2026-09-14 已确认并实施）

- 删除 Git 日志中的“刷新日志”，三个标签只保留“项目”右侧的“刷新”。手动点击立即重读当前标签的本地列表与选中内容，同时异步获取远程分支；本地内容不等待网络。获取期间按钮禁用并显示“正在获取远程更新…”，仍可切换标签、查看文件或继续会话。
- 获取完成后更新 Git 历史与分支标记；日志未打开时标记失效，打开后再读取。保留筛选、提交、文件、已加载页数和滚动。远端分支被删除时提示所选分支不可用，用户可切换其他分支。
- 只有手动刷新触发 fetch。进入会话、打开抽屉、切换标签、任务/SSE 自动刷新、历史分页均只读本地。无 Git 仓库或无远程时正常刷新本地并提示跳过。
- 使用已有鉴权、CSRF 和 session 到项目的服务端绑定，新增 `POST /api/sessions/:id/git/fetch`，空请求体；浏览器不能传 cwd、URL、refspec 或 Git 参数。请求异步等待服务端操作结果，不创建持久队列或轮询任务。
- 单个服务进程内，同一项目的并发请求共享一次操作，跨页面也合并。按项目保留最近一次结果 10 秒防连续点击；超时、成功或失败均释放执行中的占用，缓存到期可重试。项目间独立。
- 枚举项目已配置的远程，逐个获取；整次操作最多 60 秒，单个远程最多 30 秒。使用非交互凭据与 SSH BatchMode，不弹登录窗口。限制输出大小，不返回远程 URL、凭据或原始 stderr。
- 明确指定分支 refspec，只更新 `refs/remotes/<remote>/*`，不合并、不修改工作区、暂存区、本地分支和标签；禁用标签获取/清理、子模块递归、FETCH_HEAD 写入与自动维护。允许标准 HTTPS、SSH 和本地文件 Git 传输，禁用扩展协议助手；危险远程名称拒绝执行。不能直接用遵循任意仓库 refspec 的裸 `fetch --all --prune`。
- prune 仅清理对应远程已删除的跟踪分支。多个远程部分成功时返回每个远程的成功/失败/超时结果，仍重读已更新的本地历史；失败保留原内容，提示检查网络与本机 Git 凭据，不冒充全部成功。浏览器离开不启动第二个任务；旧项目结果不能污染新项目界面。

实施顺序：服务端获取与限制 → 顶部统一刷新及状态 → 移除重复按钮 → 中英文使用说明 → 真实临时 Git 仓库、API 鉴权/参数与浏览器异步回归。核对完整测试和构建后，合并为一个中文提交。

## 打开会话时核对占用（2026-09-14 补充确认）

- 点击会话及输入区“重试”时，在发送前核对原生 writer。CLI 0.153.4 本机生成协议只有 `thread/read` 的运行状态，没有独立只读锁查询接口；`notLoaded` 不等于其他进程没有持锁。
- 显式打开调用鉴权/CSRF 保护的 `POST /api/sessions/:id/open`，用原生 `thread/resume`（`excludeTurns:true`）连接既有会话，不覆盖模型或权限，不发 `turn/start`。成功由 Web 持有，沿用导航自动释放；已有本 Web 运行/审批不重复 resume。并发打开共享操作，发送与释放遵守既有占用约束。
- writer 冲突记录为 EXTERNAL，输入区显示锁图标、“已在另一个应用中打开”“请先在那里关闭会话，才能在这里继续”和“重试”；历史与项目文件仍可读。仅再次显式打开/重试成功才能清除此标记，普通历史读取不能用 `notLoaded` 错误地解锁。
- 打开检查期间禁止发送，失败显示可重试状态并继续读取历史；后台读取期间点击重试会在读取结束后执行检查，检查完成后历史同步不阻塞已有任务插话。离开期间完成的结果不能污染新会话，成功取得的占用仍执行已有释放请求。自动轮询/SSE 历史读取不反复 resume，也不探测或抢占其他会话。
- 参考：[官方读取/恢复语义](https://learn.chatgpt.com/docs/app-server)。实现以本机生成协议为准；真实锁冲突需双 app-server 只恢复、不发送消息的验证，模拟测试覆盖并发、冲突提示、重试和导航释放。

## 实现边界

复用 React、现有布局比例存储、Git 子进程执行、diff 解析和 Streamdown，不增加直接依赖。保持消息发送、插话、会话恢复链路。异步请求丢弃过期响应，旧内容仅在对应相同资源更新失败时保留，不混淆文件或提交。

Git 历史从服务端解析当前 session 对应项目，客户端不能指定工作目录。commit/parent 必须解析并校验为仓库提交且 parent 属于提交的真实父列表；根提交使用空树比较。路径为项目相对路径、字面匹配。已有超时和输出上限继续生效。历史中的已删除文件可查看 diff，无需工作树文件存在。

参考：https://github.com/mhutchie/vscode-git-graph 。

## 实施补充与验收结果
