# 三栏工作区与 Git 历史设计

日期：2026-09-11。用户已确认；操作文案使用“中止”，不改为“停止”。

## 已确认交互

1. 中间会话栏顶部左右两端各有面板图标；工具栏只属于中间栏，右侧项目栏独立从顶部开始，不共享工具栏。两端图标，提示展开/收起左侧栏、右侧栏；图标位置始终保留；没有项目时右侧栏按钮禁用。折叠释放空间，展开恢复宽度。小屏使用互斥抽屉，关闭回到原会话位置。
2. 右栏标签为“变更｜文件｜Git 日志”。折叠不卸载右栏；重复点击标签不重置；每个标签独立保留选择及滚动。刷新更新数据但不先清空；失败保留旧内容并提示，文件消失明确显示不可用。
3. 桌面两栏可见性和宽度保存为浏览器偏好；手机每次进入默认关闭抽屉，不覆盖桌面偏好；阅读状态按项目保存，同项目会话共享。重新打开浏览器恢复标签、目录、文件、工作区/暂存区、统一/并排、源码/预览、日志筛选/提交/父提交/文件及滚动，重新读取最新数据。只保存轻量选择，不持久化文件正文或提交数据。
4. 输入区底部左侧快捷键提示，右侧为相邻的“中止”和“插话”。空闲只显示发送；中止中显示“正在中止…”，不清除草稿。
5. Git 日志只读：真实父子连线、标题、分支/标签、短哈希、作者和时间；默认当前分支，可选其他分支或全部分支；100 条一页。提交列表与文件列表一样最高 35vh，内部独立滚动并保留位置；下方常驻选择提示或提交详情。点击提交展开详情与文件，选文件看源码 diff。合并提交默认第一父提交，可切换父提交。分页边界标明未加载历史。空仓库与非 Git 目录区分，文件浏览仍可用。无 checkout/reset/rebase 等写操作，无自动 fetch。
6. .md/.markdown 默认预览，提供预览/源码切换，复用安全 Markdown 渲染和复制。项目相对链接通过鉴权文件接口且限制项目根内；http/https 新标签打开；HTML 不执行，远程图片不加载。截断提示明确。工作区与历史 diff 保持源码差异。

## 实现边界

复用 React、现有布局比例存储、Git 子进程执行、diff 解析和 Streamdown，不增加直接依赖。保持消息发送、插话、会话恢复链路。异步请求丢弃过期响应，旧内容仅在对应相同资源更新失败时保留，不混淆文件或提交。

Git 历史从服务端解析当前 session 对应项目，客户端不能指定工作目录。commit/parent 必须解析并校验为仓库提交且 parent 属于提交的真实父列表；根提交使用空树比较。路径为项目相对路径、字面匹配。已有超时和输出上限继续生效。历史中的已删除文件可查看 diff，无需工作树文件存在。

参考：https://github.com/mhutchie/vscode-git-graph 。

## 验收

覆盖左右折叠/宽度恢复、小屏互斥抽屉、标签往返、重复点击、刷新失败与资源消失、会话切换和重载后的项目状态恢复；Git 真实临时仓库中的根提交/分支/合并/重命名/删除/分页；Markdown 相对链接边界、源码切换和安全降级；原发送插话回归、全量测试、生产构建及桌面/手机浏览器检查。

## 实施补充与验收结果

- 日志每页 100 条，最多保留 100 页（10000 条）；达到上限明确提示筛选分支。继续扩大时再引入虚拟列表。
- 分页游标固定查询起点，对分支尖端 SHA 去重；最多 512 个不同尖端、编码游标最多 4096 字符，解压最多 64 KiB。超出返回明确错误，提示选择具体分支。
- Git 查询不会越过项目目录向上发现父仓库；敏感目录不能成为项目，历史敏感路径被省略并拒绝直接查询。文件与目录互换的冲突路径不递归展开为 patch，以免隐含读取敏感子文件。
- Markdown 通过共享惰性加载外壳渲染；链接在语法树中转换，原文与复制内容不变。解析器缓存按消息或项目文件作用域隔离，避免消息链接策略串入文件预览。
- 日志滚动随异步内容恢复；失败不清空同一资源的缓存。项目内链接定位到目标目录，含空格、百分号和井号的文件名按 URL 边界只解码一次。
- 全量测试、桌面/手机浏览器及生产资源验收通过；详细命令与结果见下文历史验收记录。后端新接口需服务重启生效，本次保留了运行中的服务与会话。
