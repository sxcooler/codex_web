# 自动释放反馈只提示异常

日期：2026-10-13。用户确认先落文档，再修复。

## 目的与显示规则

「任务结束后自动释放」是后台排队状态，用户无需操作。常驻绿条占据聊天阅读空间，并容易被误认为任务停止或即将被中止。移除输入区的正常释放提示，自动释放规则和任务控制保持原样。

| 状态 | 输入区提示 | 顶部状态 |
| --- | --- | --- |
| 任务运行中，释放申请已排队 | 不显示正常提示 | 继续显示运行中／等待审批／等待输入 |
| 正常释放进行中或等待交接 | 不显示正常提示 | 仍按实际状态显示正在释放占用 |
| 已确认交接 | 不显示正常提示，清除旧释放异常 | 已释放或历史浏览 |
| 释放申请存在且尚未交接，返回实际错误 | 显示释放异常 | 保持真实任务状态 |
| 正在前台核对或快照读取失败 | 暂时不显示旧释放异常 | 保留核对／同步错误反馈 |

释放异常使用现有输入区上方浮层，展开时显示错误文本，收起时显示错误摘要和「查看详情」。错误色与 alert 语义保持一致；不能因为任务仍在运行就隐藏实际释放错误。状态核对确认错误清除、申请取消或交接成功后，不残留异常。

复用现有绝对定位、滚动限制和提示容器，不增加定时器、动画、网络请求或新提示框。提示出现、隐藏以及前台核对均不改变输入框、聊天区尺寸和阅读位置。

## 实施边界与验证

- 仅修改前端提示选择与错误呈现，不更改 release-on-leave、原生 writer、释放请求、自动重试、发送和中止门控。
- 更新会话指南及前台／浮层设计中的当前规则；旧验收记录作为当时证据保留。
- 先以旧源码验证「排队时无正常提示」失败，再修改显示逻辑。覆盖正常排队、释放中、等待交接、交接成功、实际错误及错误清除。
- 桌面 1280px 与窄屏 390px，分别检查输入区展开／收起、错误浮层位置和颜色、前台核对、阅读位置及只读浏览不产生会话写入。
- 使用模拟接口及隔离原生夹具，不操作真实会话；更新 dist 时保留旧资源并核对线上字节，无需重启后端。
