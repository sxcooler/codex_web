# 任务通知停留与点击定位方案（已实施，待统一部署）

## 已确认的差异

用户已明确确认：目标是 Windows 弹出的系统任务通知。

- 当前系统通知由 `public/sw.js` 的 Push 事件创建，没有自动关闭计时器，也未设置 `requireInteraction`；停留由浏览器/系统决定。Web Push 的 TTL=300 是投递有效期，网络 timeout=10 秒也不是通知显示时间。
- Runtime 在完成或待确认事件处有 turn/item/request 上下文，但通知事件只发出 threadId/eventKey/kind；服务器 Push payload 和 Service Worker 的 notification.data 最后只保留会话 ID。
- 点击只聚焦 URL 完全相同的窗口，或打开会话页面。没有定位信息、消息 DOM 锚点和通知定位处理。已有会话页会继续保留旧滚动位置。
- 当前 route 包含 pathname 与 search，但会话正则只接受裸路径，附加查询参数会失配；不能只把 turn/item 拼进链接就认为跳转完成。
- 页面内全局提示没有自动消失计时器，主体也没有跳转处理。现有 Git/模型刷新 5 秒成功提示不是任务完成通知。

源码确认“对应位置”尚未实现；未发真实通知，不能据此断言用户这次 OS 点击事件完全未执行或准确消失秒数。

## 拟定行为

1. 完成、失败及需要确认的系统通知申请 `requireInteraction: true`，表达停留到用户点击或关闭的意图，不另写秒级关闭计时器。保留现有事件去重及同会话通知替换，避免多个浏览器标签页重复通知。
2. 系统通知保持简短：任务完成 / 任务失败 / 需要确认，配“点击查看本轮答复 / 失败原因 / 待确认项”。不携带对话正文、命令内容或本地文件路径。
3. 点击完成通知定位该轮最终答复；失败通知定位该轮失败说明；审批和输入通知定位对应待处理卡片。定位到折叠区里的对象时，先展开所在区，再滚动并聚焦，短暂高亮目标。
4. 该会话已有标签页时优先聚焦它并发送结构化定位请求。没有该会话页时打开本应用的安全本地链接；不为跳转离开并释放另一个正在编辑的会话。多页中只选择一个目标页面处理。
5. 登录失效时先登录，保留本次定位目标，成功后继续定位；通知点击不自动发送消息或接管其他应用占用的会话。

`requireInteraction` 是浏览器/平台偏好，Web 不能保证 Windows 在任何通知设置下都显示固定秒数。桌面大屏希望保留到激活或关闭的语义见 [Notifications 标准](https://notifications.spec.whatwg.org/#notifications)；真实验收须确认用户的 Chrome/Windows 行为。

## 最小实现范围

Runtime 的通知事件、Push payload 和 notification.data 显式传递 `threadId/turnId/itemId?/requestId?`，不反向解析 eventKey。Service Worker 只接受有效 ID 和同源本应用目标；复用现有登录与会话加载。

前端先按 URL 的 pathname 匹配路由，再单独解析和验证通知定位参数。App 接收已有页的通知点击消息；Session/Conversation 提供稳定锚点，并让指定过程区展开。定位期间关闭自动滚底，防止 SSE 把用户拉走。

目标未在当前历史页内时，复用既有历史分页，按已确认方案单次点击最多读取 5 页，禁止一次读取所有历史。超出范围、目标已删除或过期时，保留已打开的会话并明确提示“已打开会话，未找到通知对应位置”，提供已有“加载更早消息”入口，不能静默没有反应。

原型：[点击交互示意](2026-10-09-notification-navigation.html)。这是网页画出的通知示意，不是实际 Windows 通知截图，不证明 OS 停留或点击已经通过。

## 验收

- 原生事件 → 推送 → Service Worker → 点击 → 会话/轮次/消息目标，字段完整，不带正文。
- 前台、后台、多个标签、会话已打开和全部关闭，Windows 真正系统通知点击与停留。
- 完成、失败、审批、输入；折叠项自动展开、异步问题可交互、用户滚动位置与流式输出不争夺。
- 旧历史的有界分页、定位失败提示、过期登录恢复、无效 ID 和跨源 URL 拒绝。
- Service Worker 更新后读取兼容旧通知（只有 threadId 时明确打开会话）；页面加载尚未完成时不丢定位请求。
- 去重保持现有后端统一状态，不由前端轮询增加通知或用量请求。

## 实施与验证记录

已实施显式目标传递、停留偏好、同会话页聚焦、加载中 ready/ack 补交付、安全新页链接、登录后定位和 5 页上限。旧异步点击不覆盖新点击；正在进行的手动历史读取或完整刷新先等待原请求完成，再重查目标，不取消原请求或重复同页。失败通知优先定位失败说明，遇到滞后 SSE 也不会先定位普通答复。
