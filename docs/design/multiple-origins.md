# 多访问地址与便携配置（0.1.4）

用户已确认：允许 localhost 与私网 HTTPS 域名同时访问；首次配置本地端口后增加可选域名问题，验证后发布 0.1.4。

- 保留 `origin` 为默认打开地址，新增 `allowedOrigins` 数组作为额外允许的完整 HTTP/HTTPS 站点地址；旧配置仍兼容，不自动扩大旧实例访问范围。
- 每个请求按精确 Host 选择已配置地址；写请求的 Origin 必须与该地址匹配，同时验证原有 CSRF cookie/header。不能把两个白名单地址交叉配对，也不信任任意转发头。
- Cookie 不设置 Domain；根据本次访问地址决定 Secure，localhost 与独立域名分别登录。同一个 Host 不允许配置有歧义的不同协议；拒绝通配符、路径、凭据、查询和片段。
- 首次便携配置顺序：工作目录 → 本地端口 → 可选额外域名（回车跳过，裸域名按 HTTPS）→ CLI/密码等原有流程。保留 localhost 为默认地址，额外域名加入 allowedOrigins；只配置 Web 白名单，不安装 DNS、证书或代理。
- 配置辅助脚本增加域名时保留原有访问地址。HTTPS 入口继续支持通知，HTTP 入口不能因其他 HTTPS 地址存在而开放 Push 订阅。
- 验证：双地址登录和 Secure cookie、未知域名/交叉 Origin/错误 CSRF/伪造转发头拒绝、无效配置、首次配置提示顺序、现有脚本回归、构建、两平台便携包启停和多地址请求。
