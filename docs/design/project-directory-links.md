日期：2026-10-02。状态：已实施，本地配置已迁移；当前后台待重启生效。

## 通用配置

服务配置增加 `allowProjectDirectoryLinks`，只接受布尔值，默认 `false`。设为 `true` 后，项目内的目录联接及目录符号链接可以指向项目外目录，文件浏览、文本读取、报告读取和图片预览共用此规则。请求仍须通过项目内的路径进入；不开放任意项目外绝对路径、指向项目外的文件符号链接或 Git 写入。移除 `projectImageMounts` 的路径映射实现和本机配置，避免公开项目依赖具体设备的路径。

```json
{
  "allowProjectDirectoryLinks": true
}
```

开启表示管理员信任项目中的目录联接及其目标，包括嵌套目录联接。保留路径穿越检查、项目根目录检查、鉴权、敏感路径保护、文件类型和读取大小限制；图片仍限制 20 MiB / 4000 万像素并转换为静态 WebP。敏感路径同时检查请求路径与真实路径，避免通过别名读取 `.git`、`.env`、凭据和上传目录。失效或循环联接返回文件不可用，目录列表跳过不可读取条目；保留访问路径，不改成目标机器的实际路径。

## 被拦截链接的显示

共享 Markdown 渲染器在链接解析失败时显示原有标题和链接路径原文，以不可点击的文本呈现，不再让加固插件替换为 `[blocked]`。历史、流式回复和文件预览采用同一规则；路径只作为文本，不请求、不执行、不转为可点击链接。被拒绝的图片也保留源路径和已有拒绝提示。
