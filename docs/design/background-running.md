# 当前用户后台运行与发布方案

用户已确认：源码和便携版统一后台生命周期；Windows 不再依赖计划任务，不安装系统服务，保留当前用户和桌面会话。后台运行与登录自启分开设置。Linux 保留用户级 systemd 自启。

## 行为

- Windows 双击启动入口默认后台；PS1 可显式前台。兼容系统 PowerShell 5.1，不依赖 PowerShell 7。后台启动仅在本实例就绪后报告成功，失败保留启动窗口并显示日志路径。
- 便携包在交互配置完成后首次询问是否以后默认后台，保存选择；旧配置缺少选择时在下一次交互启动询问。非交互启动不猜测选择，未设置时保持前台。支持 `--foreground` / `--background` 临时覆盖、`--configure-startup` 修改偏好。
- 源码和便携包的后台模式共用启动、状态、停止控制逻辑。通过仅绑定回环地址、随机实例令牌保护的本地管理连接确认本实例身份；不根据端口或裸 PID 杀进程。启动失败不能把其他程序的 HTTP 200 当成功；停止走原有服务关闭和原生进程清理路径。Linux 原有前台与 systemd 路径保留文件锁和 PID 身份校验。
- 本地管理记录、日志均位于 `.local/web`，不进入发布包。Windows 日志在隐藏宿主内持续按约 1 MiB 轮转；Linux 在启动时轮转，长时间运行仍需按磁盘空间管理日志，不新增日志服务。
- 重复启动复用已管理的本实例；其他程序占用端口时提示冲突并退出。停止不删除自启，重复停止安全；旧手动启动的实例不自动接管或终止。
- Windows 登录自启使用 HKCU Run，调用同一隐藏启动入口。安装/移除检查本项目归属。移除旧计划任务时核对入口路径，不能修改其他项目的任务。
- 登录自启不等于开机未登录运行；注销后不保证运行，锁屏也不保证桌面工具可操作。暂不引入系统服务与桌面代理双进程架构。
