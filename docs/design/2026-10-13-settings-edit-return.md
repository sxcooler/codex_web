# 设置详情与指令编辑的完成出口

日期：2026-10-13。用户已确认：一起落文并修复，使用隔离测试验证。

## 人类需要完成的事

查看配置来源时不应面对无法操作的保存按钮；编辑指令后应该能明确结束编辑，回到个性化。用户无需通过尝试真实配置写入来理解界面。

配置页保留现有结构化选项编辑。比较、放弃和保存紧跟编辑区，配置文件详情移到表单之外，明确标为「配置文件详情（只读）」。详情仅解释原值、有效值和来源；没有可编辑选项时隐藏保存动作，保留只读原因和重新读取。

指令页继续编辑固定的个人／项目 AGENTS.md，不增加任意文件编辑能力。保留顶部返回入口和其他导航的草稿保护；页底提供明确的完成动作，长文本和手机上也能找到。

| 情况 | 取消并返回 | 保存并返回 |
| --- | --- | --- |
| 没有修改 | 直接回个性化，不写文件 | 禁用；不会阻碍返回 |
| 有草稿 | 放弃本地草稿并返回，不写文件 | 只写一次，成功后返回并显示保存结果 |
| 文件只读／读取失败／未选择项目 | 可返回 | 不显示无意义的保存动作 |
| 正在保存 | 暂时禁用，防止误以为取消可以撤回写入 | 显示保存中并禁用，防止重复提交 |
| 保存失败、版本冲突或结果未知 | 可以离开；不声称撤回可能已完成的写入 | 留在编辑页，保留草稿、范围和差异；冲突／未知结果先读回核对 |

保存成功返回时，先同步清除导航保护的 dirty 标记，再导航一次；焦点回到「编辑指令」。通用保存函数仍只负责保存，供范围切换和导航确认使用，不把这些动作错误地带回个性化。

个性化页先展示自定义指令入口，再展示记忆设置；保存反馈放在自定义指令入口旁。这样返回后能立即看见刚完成的操作，后续记忆设置加载也不会把焦点推到屏幕外。

保存中通过其他导航离开时，明确告知已发出的写入不会撤回，并禁止再次提交。用户已经离开后，迟到的保存响应不再导航；用户仍在导航确认框内时，成功结果完成最新的导航意图并关闭确认框，取消导航则完成原本的保存并返回。
