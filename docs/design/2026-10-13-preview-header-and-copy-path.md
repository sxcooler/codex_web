# 文件预览标题栏与复制路径

日期：2026-10-13。用户已确认先落文再实施，并补充复制按钮使用图标，与现有按钮保持一致。

## 目标与确定行为

长路径、路径滚动条与导航/全屏按钮挤在一行，使当前文件不易辨认。普通文件、工作区差异及 Git 历史预览共用标题栏；保留已有正文 DOM、缓存、阅读位置和全屏/Esc 行为。

| 行 | 左侧 | 右侧 |
| --- | --- | --- |
| 第一行 | 项目相对路径，目录省略，优先保留文件名；悬停完整显示 | 复制路径图标、全屏/收起图标 |
| 第二行 | Markdown 预览/源码，或现有差异视图切换 | 后退、前进、最近文件 |

无模式/导航操作的历史差异使用相同标题行，不增加空白操作行。目录和文件名均单行裁切，路径不出现横向滚动条。沿用现有 28px 桌面按钮、44px 窄屏/触屏触控区域及 8px 标题行间距。

复制按钮所有宽度均只显示图标，名称/悬停提示为“复制文件路径”。复制项目根目录下文件的完整绝对路径；Git 历史需加上当前选择的子模块/嵌套仓库相对目录。保留 worktree 子目录、中文、空格、Windows/Unix/UNC 路径风格，不复制预览 URL、行号或省略后的文字。原生项目根路径未取得时禁用复制，不以相对路径冒充绝对路径。

只在点击时调用 Clipboard API；成功短暂显示对勾，悬停与读屏反馈为“已复制”，不增加遮挡导航的成功浮签。失败明确提示“复制失败，请重试”，浮签定位在整个工具栏实际底部以下，适应差异视图切换按钮的不同高度。按钮尺寸固定、反馈不挤动标题和正文；切换文件后不显示前一个文件的迟到反馈。复制不请求文件接口、不刷新预览、不改变占用或持久化状态。
