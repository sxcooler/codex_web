# 0.1.6 发布验证

功能基线为 `598df4c`。发布分支从上一公开版本导入当前净改动，保留原开发提交及其中文说明；公开文件泛化现场会话标识，不推送本地诊断记录。

本版包含应用增量更新与独立恢复入口、Windows 品牌自启动、原生提问点选、模型目录刷新、设置页版本信息、额度重置兼容性和会话终态恢复修复，以及完整浏览器标题、附件限额和移动端输入反馈优化。

## 增量更新支持范围

| 原安装 | 0.1.6 应用更新 ZIP |
| --- | --- |
| 官方 0.1.5 Windows x64 完整包，运行环境未修改 | 使用 win-x64-update.zip，先停止旧服务，通过包内更新脚本引导升级 |
| 官方 0.1.5 Linux x64 glibc 完整包，运行环境未修改 | 使用 linux-x64-update.zip，先停止旧服务，通过包内更新脚本引导升级 |
| 0.1.4 及更早版本 | 不适用；使用完整包迁移 |
| 源码安装、自建依赖、跨平台安装 | 不适用；使用对应部署或完整包迁移流程 |

更新包不包含 Node 或 node_modules。版本号不是唯一判断条件，更新器还必须确认运行环境指纹及原安装文件散列。安装文件系统需支持硬链接，如 NTFS/ext4。0.1.5 尚无 Update 入口，引导命令见便携包指南及 GitHub Release。

## 发布门槛

Windows 与 Linux 从同一个干净提交分别原生构建完整包及更新包；通用源码 ZIP 不含 Git 历史。两平台运行全量回归、全新包启停和登录验收、应用更新与用户数据保留检查；额外从官方 0.1.5 原始压缩包验证升级。所有 manifest.sourceCommit 必须与版本标签一致。

核对五个压缩包的排除项、源码一致性、运行环境兼容指纹和 SHA256。验证通过后才公开 GitHub Release，最终测试数、产物体积和散列记录在 Release。发布不重启日常服务，不调用真实模型或消耗额度重置。
