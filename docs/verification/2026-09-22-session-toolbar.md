# 固定会话顶栏与输入区收起验收

日期：2026-09-22。依据：[会话工作区设计](../design/session-workspace.md)。用户确认后实施，未修改后端接口、依赖或运行服务。

## 实现

- 会话标题区合并到原顶栏，依次显示侧栏开关、项目、标题、操作、状态、用量、侧栏开关。项目名支持 Windows/Linux 路径兜底，标题保留全文，剩余宽度不足时由 CSS 省略，悬停可看全文。
- 原生 popover 只提供同样式的“刷新”“释放”，调用原有会话动作，刷新/中止/操作中反馈保留在入口。非会话顶栏保持原样；“历史浏览”状态保留。
- 输入区收起后保留草稿/附件摘要、中止、待处理定位及异常详情入口。输入组件保持挂载，上传继续；隐藏时移除表单粘贴/拖放监听，关闭权限菜单。
- 折叠状态只保存在 `PaneLayout` 的 React 状态中，切换会话沿用，刷新页面重置。草稿仍用现有机制。桌面展开聚焦输入框，手机不主动聚焦；历史阅读保留位置，跟随模式保持底部。
- 模型/权限加载错误、附件数量/大小校验错误也会进入收起态摘要，避免异步错误被隐藏。
