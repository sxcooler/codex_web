# 0.1.7 发布验收说明

日期：2026-10-07。本说明记录源码冻结前的验证与发布门槛；最终打包、安装、升级和远端核对结果、数量及散列，以 [v0.1.7 GitHub Release 正式记录](https://github.com/sxcooler/codex_web/releases/tag/v0.1.7) 为准。正式公开版本必须通过下列全部门槛。

**Codex Web 0.1.7 要求 Codex CLI >=0.160.1（本版开发／实测基线）**，仅接受可识别的稳定版本。旧 0.1.6 安装须先独立升级 Codex CLI，运行 `codex --version` 核对版本，再执行 0.1.7 应用更新；应用更新不会升级 CLI。版本过旧、预发布或无法识别时，新服务拒绝启动，更新器按既有规则保留或回滚应用。

## 更新范围

- 设置页分为常规、配置、个性化、使用情况、已安装插件和 Codex Web。原生默认模型／推理强度、速度、权限、搜索和记忆配置使用固定白名单、版本核对与保存后回读；个人／项目指令支持差异预览及未保存保护。
- 已完成回答支持分支到新聊天和只读记忆引用。分支不发送任务、不回滚项目文件；空预览分支通过受控补充读取保持可见。
- 插件页只读显示原生已安装状态与部分读取失败；启用状态不等于授权、连接或当前会话可调用。
- 浏览器发送快捷键、会话排序及布局偏好；用量余额显示、历史消息时间、文件导航、Markdown 定位和目录联接预览。
- 登录活动续期、会话同步与活动轮次恢复、子 Agent 过滤、JSON／SSE 容错及安全重启预检。
- 不再提供原生停用／迁移的 `untrusted` 和 `on-failure` 审批写入；旧值仍显示，仅权限部分只读，独立模型与搜索可继续保存。运行时时间 helper 纳入既有 `src/codex/` 目录，完整包与标准旧更新器均可处理。
- Git 全分支日志按原生日期顺序显示，列表与详情均使用提交时间；保留子提交先于父提交、真实连线与冻结分页，避免旧分支段挡住其他分支的新提交。

## 公开内容与证据边界

公开分支从此前公开 master 导入开发净改动；未直接推送含现场信息的开发历史。文档中的个人路径、原生会话／轮次及上传标识已替换为公开示例，历史诊断限制和失败分母保留。测试中固定的合成标识、假账户和隔离密码是 fixture，不是现场凭据。

自动规则扫描不能识别任意格式的秘密。最终归档及最终发布提交仍需复查；`.local/`、原生数据、认证、附件、日志、数据库和未脱敏截图不得进入资产。历史验收记录不证明当前服务已更新，本轮不重启用户日常服务。
