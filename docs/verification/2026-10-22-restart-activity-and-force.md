# 活动检查与单弹窗重启验收

日期：2026-10-22。对应 [spec](../design/2026-10-22-restart-activity-and-force.arch.md) 与 [实施计划](../superpowers/plans/2026-10-22-restart-activity-and-force.md)。

## 交付行为

- 点击原有入口自动检查，在同一个 dialog 列出当前活动会话、审批／输入、子 Agent 与临时任务。无活动时绿色“重启”，有活动时警告色“强制重启”，没有第二步、额外弹窗或勾选。
- 检查不完整保留已确认的会话和具体异常，不能普通／强制执行；原始错误仅在详情查看，正常结果与历史记录不变为重复警报。
- 普通及强制确认都会重新核对范围；新任务、新轮次或新实例使旧确认失效，在同一弹窗更新清单，不自动升级为强制或重复提交。
- 共享判定允许可靠终态的 systemError，不一律放行空历史或外部占用；保留历史错误，不靠卸载、接续或重新发送来修正状态。
- 强制授权贯穿 API、受管 Windows 调度及私有控制端。只停止明确持有的子进程；普通调用继续保持空闲默认保护，Windows 保留 90 秒安排和桌面／实例／结果校验。

## 审查修正

1. 确认受管子进程退出后，清除旧轮次与交互索引，结算等待者并发送同步变化。未收到原生终态的本地任务保留“结果可能未知”，不伪造成功或自动重发。回归包含本地待输入及原生中止无响应。
2. 私有控制端在准备成功后，即使客户端已断开也继续停止 Web；响应完成和关闭共用一次处理，并沿用既有 shutdown 去重。隔离 TCP fixture 在准备期间断连后，确认 worker 退出且只关闭一次。
3. 读取 idle 期间出现较新的 active 通知时，旧读取不能使该线程被当作已检查。无法确定轮次则报告 unknown 并禁用执行；覆盖已有本地 state 和检查时才创建 state 两种情况。
4. 显式强制关闭在正常宽限期后使用 SIGKILL，并等待退出确认。退出未确认时保留原实例引用和维护状态，不另建后台。fixture 忽略 SIGTERM，并检查实际传给 owned child 的信号；本次运行环境是 Windows，没有据此宣称 POSIX 实机已验证。

两项执行取舍：使用原有忽略目录和 Windows 命令记录证据，代替技能中的 shell 包装器，影响仅是记录位置；保留复用的 worktree 与忽略目录证据，避免按技能清理步骤删除既有现场，代价为少量本地磁盘占用。无延期的次要发现。

## 浏览器验收

Browser plugin 未提供，使用仓库 Playwright（Windows Edge）和已有 Playwright Chrome MCP。路径为真实 App 的 `/settings?section=web`，所有 API 用演示数据截获，真实重启接口未被调用。

覆盖 1280／1440px 与 360／390px、中英文及现有暗色。核对标题／路由、非空页面、框架错误覆盖层、pageerror、截图、相邻控件、按钮计算颜色与页面横向溢出。真实 dialog 保留取消首焦点、Tab、Enter／Space、Esc 及返回入口焦点。检查详情按文本显示，长行、长清单在正文单一滚动区内显示，手机底部操作保持可见。

Chrome MCP 另外在隔离前端 `127.0.0.1:4197` 操作完整 App：1280px 中文绿色普通重启与 390px 中文警告色强制重启，执行请求均由演示 handler 接收。已查看截图；无 pageerror、无框架覆盖层、无横向溢出。额外拦截了用户活动触发的鉴权续期模拟请求，没有真实会话写入。

证据保存在本 worktree `.local/restart-activity/` 和 `test-results/restart-activity-*/`。已查看普通／强制、桌面／窄屏、英文、长清单及 Chrome 截图。测试使用演示标题与项目，不提交真实会话内容。

## 生效与验证边界

本次未重启或强制重启真实后端，未停止任何真实任务。代码和运行服务版本分开判断：新报告协议及强制执行需要后端重启后生效，新前端不能单独交付给旧后端。

现场最初的 503 尚未在新后端上复核；本次证明的是已复现的判定缺口得到修复及错误可定位，不将其写成原生故障已恢复。未验证真实 Linux 服务重启、Safari、手机实机或实际屏幕阅读器语音。强制操作不回滚已写文件或外部动作，已脱离受管进程的工具任务可能继续运行。

实现已完成最终审查及回归，按计划压缩为一个中文实现提交后快进集成到本地 master，提交正文保留原任务提交信息。没有推送 GitHub 或 worktree 分支。生产后端和前端静态资源未部署，新行为仍待后端与前端一并更新后复核。
