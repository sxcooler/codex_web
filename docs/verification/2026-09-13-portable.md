## v0.1.1 回归

新增文件栏图片预览、Windows CMD 入口与后台启动，并包含手机图标安全边距修复。Windows 完整测试 178 通过 / 5 跳过，Linux 177 通过 / 6 跳过，两平台生产构建通过。跳过项为另一平台专属检查、未开启的 Linux 用户 systemd 集成检查及需要真实产物的检查；最终解压产物另行验证。

- 图片接口验证登录、项目边界、忽略/敏感文件、坏图、10 MiB 与 4000 万像素限制；SVG 转成 WebP，长边最多 2048 像素。
- 浏览器使用 1280px 桌面与 390px 手机视口，验证图片加载、刷新、失败后换图恢复、没有额外正文 JSON 请求，以及原有文件/日志/Markdown 状态回归。图片响应使用本项目图标 fixture；后端由接口集成测试覆盖。预期的坏图 404 不代表应用运行异常。
- Windows 在真实 PowerShell 7 和内置 5.1 下验证 CMD 参数、带空格路径、退出码；5.1 下验证隐藏进程启动、重复启动保护、停止后 Node 退出、计划任务回退选择、Unicode 配置保持。计划任务和网络 CLI 使用隔离替身，不改变开发机的任务或网络配置。
- `output/` 整体忽略，两张未采用的生成图已从项目输出目录删除，浏览器截图与日志不进入发布物。

浏览器检查可从仓库目录运行：先启动 `npm run dev -- --host 127.0.0.1 --port 4181 --strictPort`，然后使用 Playwright CLI 打开该地址，并执行 `run-code --filename tests/image-preview.browser.js`。普通的 `tests/workspace-panels.html` 仍可独立运行；`?images=1` 的图片用例需要该检查脚本提供响应。
