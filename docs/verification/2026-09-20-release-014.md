# 0.1.4 发布验证

本版本包括多访问地址配置、便携首次启动可选域名、聊天文档链接、历史图片独立加载与自动缩略图、右侧栏独立折叠，以及 [预览滚动性能修复](../design/workspace-panels.md)。用户已再次完成远程验收并确认发布。以下跨平台结果包含最终性能修复。

- Windows / Node 24.20.0：220 项测试，215 通过、5 跳过、0 失败。跳过 4 项 Linux 检查及独立便携包验收。
- WSL Ubuntu 22.04 非 root / Node 24.20.0：220 项测试，214 通过、6 跳过、0 失败。跳过 4 项 Windows 检查、需可用用户 systemd 环境的集成检查及独立便携包验收。Linux 生产构建通过。
- Windows 生产构建与类型检查通过；保留既有 Markdown/语法高亮大分块提示。
- 桌面 1280×900 / 手机 390×844：折叠与预览性能专项 4 组、原有面板/Git/文档链接/发送/会话性能等 18 组浏览器回归通过；历史缩略图在两种尺寸下验证自动加载、视口外延迟、原图按需及失败重试。浏览器测试使用隔离模拟 API，不操作用户原生会话。
- 新增折叠偏好测试先失败后通过；旧 localStorage 字段兼容，项目间状态隔离。多地址测试覆盖精确 Host、匹配 Origin/CSRF、按地址设置 Secure Cookie，跨地址写入及未知 Host 被拒绝。

## 产物发布门槛

源码 ZIP、Windows x64 ZIP、Linux x64 glibc tar.gz 从同一提交构建，便携包的 manifest 必须引用该提交。两平台均对全新解压副本运行 `tests/portable-package.test.ts`，核对文件散列、内置 Node、前台与后台启动、重复启动、状态和停止，以及 localhost/额外域名认证；不启动模型任务。

最终归档检查排除 Git 数据、私有配置、日志、上传文件和生成图片目录，检查已知个人路径/主机信息及源码与提交的一致性。生成三包 SHA256SUMS.txt，产物检查的最终结果记录在 GitHub Release。日常服务不需要为打包而停止。
