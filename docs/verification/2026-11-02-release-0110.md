# 0.1.10 发布验收

本版汇总 0.1.9 之后的会话可靠性、文件输入与预览、插件与集成、侧栏及重启体验改进。便携 Node 固定 **24.20.0**，Codex CLI 最低稳定版本继续为 **0.160.1**，运行依赖锁定内容不变。

## 用户可见变化

- 修复已完成轮次误报中止、旧快照覆盖新终态及失败核对无法人工重试；保留真实中止和失败。分支会话继承父模型与推理强度，补充分支确认和编号。
- 支持长文本粘贴转 Markdown 附件，保留上传文件扩展名，完善文件粘贴与拒绝提示；原图可通过受保护的文件接口查看。
- 增加插件与集成管理、扩展目录缓存与加载状态、官方分类数量、品牌图标和加载失败兜底；完善富内容与输出标记的安全展示。
- 新任务可打开文件侧栏，各标签独立刷新；双侧栏在窄屏转为抽屉，完善导航、手动重启及终态子任务的活动判断。
- 默认崩溃报告排除环境与网络详情，完善服务启动和便携包运行文件范围。
- 修复 Linux 前台服务在启用诊断参数后无法通过 Stop 安全停止的问题；保留 PID 身份与其他进程保护。

## 发布门槛

依照 [发布计划](../superpowers/plans/2026-11-02-release-0110.md) 和 [发布指南](../guides/publishing.md)，仅发布通过以下检查的产物：

- 从同一冻结公开提交，在 Windows x64 和 Linux x64 glibc 原生执行全量 Node 测试、类型检查、生产构建与打包。
- 验证全新解压包的启动、登录、停止及应用更新；通过官方 0.1.9 原始 Update 入口升级，检查配置、认证、用户数据、外部项目及升级后登录。
- 运行受影响入口的浏览器回归，查看桌面／窄屏、中英文代表截图，记录焦点与相邻控件布局的实际覆盖范围。
- 审计五个归档及新增公开 Git 对象，校验源码白名单、sourceCommit、逐文件 size／SHA-256、运行环境指纹及 Linux 执行权限。
- 六个附件上传草稿并核对大小和散列后正式公开；匿名复核 latest、校验文件与更新包实际下载。

最终测试计数、散列、升级结果与未验证范围附 [v0.1.10 发布页](https://github.com/sxcooler/codex_web/releases/tag/v0.1.10)。本文件定义本版发布范围和门槛，不用旧版结果替代当前验证；详细日志与失败记录保留在本地忽略目录。

## 已知限制

远程上下文压缩的网络断流不在本次修复范围，仍可能导致会话无法继续；会话终态同步修复不能解决上游传输故障。当前版本未包含自定义模型提供商功能。

不发送真实模型任务，不修改日常 Codex 配置，不重启日常服务。实体手机／iOS Safari、ARM64、Alpine/musl、macOS 和早于 0.1.9 的直接升级不在本轮验证范围。生产构建的既有大 chunk 提示保留。
