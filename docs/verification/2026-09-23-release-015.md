# 0.1.5 发布验证

按用户确认的 `6b82d57` 功能基线发布，本次仅更新版本号和发布记录。版本包含首页沿用最近会话的模型、推理与权限选项，紧凑输入区和单行会话顶栏，推理摘要与子 Agent 展示，图片按需预览、Mermaid 预览及滚动修复，以及历史加载性能、请求超时区分和可选运行诊断。

- Windows / Node 24.20.0：251 项测试，246 通过、5 跳过、0 失败。跳过 4 项 Linux 检查及独立便携包验收。
- WSL Ubuntu 22.04 非 root / Node 24.20.0：251 项测试，244 通过、7 跳过、0 失败。跳过 5 项 Windows 检查、需可用用户 systemd 环境的集成检查及独立便携包验收。
- Windows 类型检查与生产构建通过，保留既有 Markdown、图表和语法高亮大分块提示。
- 首页选项恢复及会话操作的 8 项浏览器回归通过，覆盖手机与桌面输入、面板拖动、会话释放、请求不确定状态、附件和新建任务选项。使用独立模拟 API，不操作用户原生会话。

## 产物发布门槛

Windows x64 ZIP、Linux x64 glibc tar.gz 和源码 ZIP 从同一发布提交生成；便携包的 `manifest.json.sourceCommit` 必须等于该提交。Linux 在独立目录安装原生依赖并构建，不复用 Windows 的依赖目录。

两平台均对全新解压副本运行 `tests/portable-package.test.ts`，核对文件散列、内置 Node、认证、前后台启停、重复启动和额外访问域名，不启动模型任务。复查归档排除项、文本隐私、源码一致性及本次待推送历史，生成三个压缩包的 `SHA256SUMS.txt`。最终产物验证结果记录在 GitHub Release；打包不重启日常服务。
