# 0.1.9 发布验收

本版汇总 0.1.8 正式版之后的国际化、安装接入、会话可靠性和项目面板体验改进。Codex CLI 最低稳定版本继续为 **0.160.1**，便携 Node 固定 **24.20.0**；仅更新应用版本字段，不改变运行依赖锁定内容。

## 用户可见变化

- 支持中英文界面和跟随浏览器的语言偏好，修正语言控件与英文提示；英文 README 作为首页，中英文使用不含真实用户内容的演示截图。
- 安装流程可引导使用已有 Tailscale，完成私网 HTTPS 接入；仍需独立安装、登录官方客户端。补充直连与家庭网络配置说明。
- 区分会话空闲、执行失败、中断、回复缺失及待同步状态，保留真实错误与恢复入口，减少正常自动恢复期间的重复权限提示和常驻失败提示。
- 重启操作一次检查并列出活动会话；检查完成后根据状态提供普通或强制重启。后台只读列表查询不再当作运行任务；检查未知时保留明确提示，执行前继续校验。
- Git 日志在未选提交时充分使用高度；选中后按提交／文件两区展示。点击文件直接打开预览，支持上一／下一、窄屏全屏、键盘操作、关闭后保留同文件阅读位置及缓存。

## 已有功能验收

本次发布基于已经完成开发验收的代码。Git 预览改动完成 47 项浏览器回归，额外键盘 Enter 重开 2 项通过；开发全量 Node 共 833 项，828 通过、5 环境跳过、0 失败。类型检查、生产构建及共享预览的既有浏览器脚本通过，独立审查无阻断问题。详见 [Git 预览验收](2026-10-23-git-history-two-sections-dialog.md)、[活动检查与重启验收](2026-10-22-restart-activity-and-force.md) 和 [会话反馈验收](2026-10-20-turn-outcome-feedback.md)。这些组存在重叠，不合计为独立测试总数。

## 正式产物门槛

Windows x64 和 Linux x64 glibc 从同一冻结公开提交原生构建，生成两平台完整包、两个应用更新 ZIP、一份通用源码 ZIP及 `SHA256SUMS.txt`。只发布通过下列检查的产物：

- 两平台全量 Node 测试、类型检查、生产构建，以及新解压便携包的启动、登录、停止与应用更新。
- 官方 0.1.8 完整包使用其原版 Update 入口，在隔离的运行实例中升级到 0.1.9；配置、认证、用户数据及外部项目文件保留，重启后仍可登录；含空格路径可用。
- 核对运行环境文件的 size／SHA-256 与 runtimeFingerprint，manifest 的 sourceCommit 为同一公开冻结提交；更新包不含运行依赖或用户数据。
- 按白名单扫描五个归档及新增公开 Git 对象，排除原生用户目录、认证、数据库、附件、日志、开发 worktree、原始截图和本地证据；已有公开脱敏文档保持原样，不将私有开发历史整体推送。
- 上传后核对资产数量、名称、大小及 SHA-256，检查匿名下载和 latest 版本。正式构建、安装升级与远端校验的最终计数、散列和结果在 [v0.1.9 发布页](https://github.com/sxcooler/codex_web/releases/tag/v0.1.9) 一并提供。

不发送真实模型任务，不改日常 Codex 配置，不重启日常服务。浏览器验收使用演示数据与 Chromium；实体手机／iOS Safari、其他架构和更早版本直接升级未在本轮验证。已知非阻断项：Git 两区同时折叠时标题间距偏大；构建仍有既有大 chunk 提示。
