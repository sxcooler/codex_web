# 第二阶段实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. 按复现失败、最小实现、验证顺序完成。

**Goal:** 实现已评审的第二阶段完整功能，保留现有配色。
**Architecture:** 复用 React/Fastify、官方 app-server、Web SQLite；原生 Thread 仍为历史与执行权威，Web 只适配。

**Spec:** ../specs/2026-09-11-phase2-design.md

## Global Constraints

- 当前获授权实施全部第二阶段；开发结果汇总到 develop，master 保留基线。
- 不重启当前对话/生产服务，不更改 Codex 全局配置、原生历史和他方锁。
- 各任务只修改分配文件，跨文件集成由主代理统一完成；提交时只 add 自己的文件。
- 先补针对性失败回归，再实现；运行 node --test 对应测试，最后全套与构建、浏览器验证。
- 本轮提交最终 squash 为一个中文提交，正文保留原提交说明。
