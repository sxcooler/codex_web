# 操作结果提示收敛与重启记录修复计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 把已结束的操作反馈与当前运行状态分开，清除误导性的常驻提示，同时保留结果未知、冲突及实际错误的处理入口。

**Architecture:** 沿用现有操作接口和提示样式。重启状态展示单独处理历史记录、当前操作和有限只读核验；其他入口只调整反馈生命周期，不增加统一通知系统。

**Tech Stack:** React、TypeScript、Fastify、现有 Node/Playwright 测试；不新增依赖。

**Spec:** 本文件的“排查与设计”部分；用户已确认先前讨论的反馈规则，并要求扩大同类检查、先落文档再实施。

## 全局约束

- 重启结果的 `failed` 记录必须保留，不能因后来服务可访问就改写为成功。
- 仍使用原来的 90 秒延迟、到期后 120 秒未知判断、任务空闲检查和受管进程保护；不自动重新安排重启，不强杀进程。
- 自动核验只调用 GET，5 秒间隔，仅在安排时间起的既有 120 秒核验窗口内执行；独立到期计时器取消挂起读取并转入待核实。每次读取沿用 30 秒上限，保留手动核验及恢复前台时的只读核对。
- 未保存草稿、版本冲突、未知写入结果、额度操作幂等标识、发送与审批保护保持原样。
- 成功短反馈使用已有 5 秒约定；需用户比较或核实的说明不计时隐藏。关闭提示只改变展示。
- 共用入口检查中英文、390/1440px、键盘焦点和相邻控件；使用隔离模拟接口，不执行真实重启、额度重置或 Git 远程获取。
- 本轮一个中文提交；不推送工作树分支，不自动发布或重启日常后端。

## 排查与设计

| 入口 | 已确认的问题或现状 | 处理 |
| --- | --- | --- |
| Web 重启 | API 长期返回最后一次结果；页面在“运行状态”下常驻终态红框，不显示时间；终态检查按钮反复读取同一文件 | 终态默认折叠为“上次 Web 重启记录”，显示时间、结果及可用原因；历史记录不作为当前故障告警。当前页面发起的失败当次可见、可关闭，成功 5 秒收起；只有进行中/未知保留核验入口 |
| Web 重启核验 | 目前只在进入设置及手动点击时读取，安排后无自动确认 | 安排到期后有限只读核验；前台恢复/网络恢复时核对待处理结果；请求取消、并发和旧响应不得覆盖新的操作 |
| 重启 Codex | 成功提示直到下一次操作或离开页面才消失 | 5 秒后清除，不影响实际模型重载 |
| 配置保存 | 保存成功提示常驻；普通字段编辑已有清除逻辑，但权限预设与放弃修改会留下旧提示 | 仅“已保存”5 秒后清除；权限预设/放弃修改清除对应旧反馈；草稿仍存在时保留重新读取后的核对说明，冲突及未知结果保护不变 |
| Git 获取 | 成功已在 5 秒后清除；失败/不确定结果不能手动收起 | 保留失败与不确定反馈，允许显式关闭；不改变获取次数、超时或当前文件读取错误。关闭后焦点回到刷新按钮，刷新仍禁用时回到活动页签 |
| 额度操作 | provider 存活期间保留上次操作反馈，关闭并重开面板仍可看到旧结果 | 已确认的完成结果 5 秒收起，其他已结束反馈允许关闭；存在 pending 或存储问题时保留核验说明及操作保护，不提供清除未知结果的入口 |
| 指令编辑 | 保存后返回；重新读取说明要求核对未保存文本 | 保留现有行为，不计时清除核对说明 |
| 通知、插件及用量读取 | 展示真实能力/连接状态、部分读取失败或陈旧数据 | 保留；它们是当前状态和处理依据，不当作已结束操作结果 |
| 全局提醒与会话释放 | 全局已有关闭按钮；正常释放已隐藏，实际错误随核对更新 | 保留现有规则，不再增加定时器或重试 |

后端 `RestartStatus` 增加可选 `finishedAt` 和终态 `reason`。只接受有效时间与有限长度文本；未知/进行中不带旧终态原因。前端兼容旧后端：缺失结束时间时显示安排时间，缺失原因时给出未记录原因的说明，不臆测活动任务或启动失败。

## Review Focus

1. 重进页面的旧失败与本次新失败必须区分；新失败仍需被看到。
2. 新操作、切换页面或恢复连接时，旧响应/旧定时器不能覆盖新结果。
3. 服务暂时不可达不等于重启失败；未知结果仍禁止重复安排。
4. 原因缺失、非法时间、旧后端响应必须能正常展示，不把未知改为成功。
5. 额度 pending 与配置写入未知不能被关闭按钮或成功计时器清掉；关闭操作须恢复合理焦点。
